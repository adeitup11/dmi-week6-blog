🚀 Gotto Job: Backlog Refinement & Sprint 1 in Jira

Hands-on Scrum, Jira, Agile planning, sprint execution, Git, deployment, and continuous improvement.

← Back to DMI Blog

As part of the DevOps Micro Internship (DMI) Cohort 3 with Agentic AI, I completed a hands-on Scrum and Jira exercise focused on Agile planning, backlog refinement, sprint execution, and delivering a small UI improvement.

In this assignment, I worked in Solo Mode, taking on the responsibilities of the entire Scrum team.

👥 My Scrum Responsibilities

  • 📌 Product Owner: Prioritized the highest-value UI improvements.
  • 📋 Scrum Master: Planned Sprint 1 and managed the Scrum process.
  • 💻 Development Lead: Implemented and verified UI enhancements.
  • 🚀 DevOps Lead: Committed changes with Git, deployed the update, and verified the live application.

✅ What I Accomplished

  • Created a Team-managed Scrum project in Jira
  • Built a prioritized product backlog with an Epic and six user stories
  • Estimated work using Fibonacci Story Points through Planning Poker
  • Planned and started Sprint 1 with a clear Sprint Goal
  • Created subtasks for development, verification, deployment, and documentation
  • Explored Jira reports, including the Burndown Chart
  • Delivered a UI improvement, committed the changes with Git, deployed the update, and tracked progress in Jira
  • Completed a Sprint Retrospective, reflecting on Scrum values and continuous improvement

🧠 What This Assignment Strengthened

  • Agile Scrum framework
  • Jira Software for project management
  • Product backlog refinement
  • Sprint planning and execution
  • Story point estimation
  • Git version control
  • UI deployment workflow
  • Continuous improvement through retrospectives

Every assignment reinforces that Agile is more than a framework — it’s a disciplined way of planning, delivering, and improving software through collaboration and iterative progress.

A big thank you to the DevOps Micro Internship (DMI) mentors and community for providing practical, real-world learning experiences.

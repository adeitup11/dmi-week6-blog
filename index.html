🚀 Week 6 Assignment Completed!

Deploying EpicBook on an Ubuntu VM with MySQL RDS and a Secure Cloud Network

I’m excited to share my progress from Assignment 4: Deploying EpicBook on an Ubuntu VM with MySQL RDS and a Secure Cloud Network as part of the DevOps Micro Internship (DMI) Cohort 3 with Agentic AI.

For this assignment, I deployed a full AWS-based application architecture designed around security, network segmentation, and end-to-end connectivity.

☁️ What I Built

🔹 AWS VPC Architecture

  • Created a custom VPC: 10.0.0.0/16
  • Configured separate public and private subnets
  • Attached and configured an Internet Gateway
  • Configured routing for the public subnet

🔹 Security & Networking

  • Implemented separate security groups for EC2 and RDS
  • Restricted SSH access to my IP
  • Allowed HTTP/HTTPS where required
  • Restricted MySQL 3306 access to the EC2 security group instead of exposing the database publicly
  • Configured RDS with Public Access: No

🔹 Compute & Web Server

  • Deployed an Ubuntu EC2 instance
  • Installed and configured Node.js
  • Installed and configured npm
  • Installed and configured Nginx
  • Installed the MySQL client
  • Configured Nginx as the web server and reverse proxy

🔹 Database

  • Deployed MySQL RDS inside the private network
  • Created the epicbook database
  • Connected to RDS securely from EC2
  • Verified database connectivity and tables

🔹 Application Deployment

  • Cloned the EpicBook application from GitHub
  • Installed Node.js dependencies
  • Configured environment variables for RDS connectivity
  • Started the Node/Express backend
  • Verified the application was listening and responding

🔹 End-to-End Testing

Successfully tested the flow:

User → Internet → Nginx → Node.js/Express → Private MySQL RDS

This project gave me practical experience with AWS networking, EC2, RDS, security groups, Linux administration, Nginx, Node.js, MySQL, environment configuration, and troubleshooting cloud connectivity issues.

💡 What I learned
One of the biggest lessons from this assignment was that getting an application running is only part of the job — understanding why components cannot communicate, how security groups control traffic, and how to troubleshoot each layer is equally important.
💡 Key takeaway: Secure cloud architecture starts with proper network segmentation and least-privilege access.
